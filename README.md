

SORTZEN is a simple and smart file organization web application built using Python and Flask. It automatically categorizes uploaded files into separate folders based on their file extensions, making file management easier, faster and more organized.

---

## 🌟 About the Project

Managing multiple files can become confusing and time-consuming. SORTZEN provides a simple solution by automatically sorting files into appropriate categories.

With just one click, users can upload multiple files, organize them automatically and download the organized files as a ZIP folder.

---

## 🚀 Features

- 📂 **Multiple File Upload:** Upload multiple files simultaneously.
- ⚡ **Automatic File Sorting:** Categorizes files based on their extensions.
- 📁 **Smart Categorization:** Separates files into different folders.
- 📊 **Organization Summary:** Displays the total files, organized files and categories.
- ⬇️ **ZIP Download:** Download all organized files in a single ZIP folder.
- 🌙 **Dark Mode Interface:** Simple and elegant dark-themed user interface.
- 💻 **Easy to Use:** Organize files with just one click.

## 📸 Application Workflow

1. Open the SORTZEN web application.
2. Select multiple files from your device.
3. Click the **Organize Now** button.
4. SORTZEN automatically categorizes the uploaded files.
5. View the organization summary.
6. Download the organized files as a ZIP folder.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/pratyusha71/SORTZEN-Automated-File-Organizer.git
```

### 2. Navigate to the Project Folder

```bash
cd SORTZEN-Automated-File-Organizer
```

### 3. Install Required Libraries

```bash
python -m pip install flask
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

Visit:

```text
http://127.0.0.1:5000
```
